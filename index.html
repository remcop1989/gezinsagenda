Afspraken

Geldt vanaf het moment dat je dit aanzet, voor nieuwe en bewerkte afspraken. Bestaande afspraken zonder deelnemer blijven gewoon bestaan — gebruik de filter "Geen deelnemer" in de agenda om ze terug te vinden.

Meldingen

Als dit aanstaat, krijg je op dit apparaat een melding zo'n 15 minuten voor een afspraak begint — maar alleen als de app hier onlangs open is geweest. Dit is geen gegarandeerde achtergrond-pushmelding.

Gezinscode & back-up

Alle gegevens worden gesynchroniseerd via jullie gezinscode — elk apparaat met dezelfde code ziet dezelfde agenda. Gebruik export/import als extra back-up of om iets terug te zetten.

👋 Welkom bij jullie Gezinsagenda

Spreek samen één "gezinscode" af (mag alles zijn, bijv. familie-jansen-thuis). Iedereen die dezelfde code invoert op zijn eigen apparaat, ziet en bewerkt dezelfde agenda.

Nog geen code? Verzin er gewoon zelf een (mag alles zijn) — die wordt automatisch jullie eigen, aparte agenda.

Code vergeten? Vraag 'm bij een gezinslid dat nog is ingelogd (staat bij hen onder Instellingen).

Deze code werkt als een wachtwoord: bewaar 'm samen ergens veilig en deel 'm alleen met elkaar.
